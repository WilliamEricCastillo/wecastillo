# Personal Website

This is my personal website, showcasing my portfolio, projects, and interests. Although it cannot be deployed externally, you can visit it at [https://williamericcastillo.github.io/wecastillo](https://williamericcastillo.github.io/wecastillo).

## Features

- Developed and deployed using React, with hosting on GitHub Pages.
- Utilized Material UI to achieve sophisticated card designs, enhancing the visual appeal of the website.
- Integrated an EmailJS-powered email form for streamlined communication, making it easy for visitors to reach out.
- Incorporated Google Analytics to monitor website traffic, user behavior, and engagement, providing valuable insights for optimization.
- Leveraged the NASA API to showcase Astronomy photos of the day on the website, adding an interactive and educational element for visitors.

## Technologies Used

- React
- GitHub Pages
- Material UI
- EmailJS
- Google Analytics
- NASA API

## Usage

To explore the website, simply visit [https://williamericcastillo.github.io/wecastillo](https://williamericcastillo.github.io/wecastillo) in your web browser.
